# 渡口

老陈蹲在渡口的石阶上。青苔从砖缝里爬出来，一直爬到他的胶鞋底——湿的。上游漂来几片槐树叶子，卡在石缝间，不动了。

对岸的船还没来。

他摸出半包皱巴巴的香烟，滤嘴被汗浸得发黄。打火机咔哒响了三四下，风从河面上斜切过来，火苗就歪向左边。他用手拢住，烟点着了，吸进去的却大半是河风。

水面上漂着个塑料袋，白得刺眼。它一会儿沉下去，一会儿又浮起来，像在挣扎，又像只是随波逐流。老陈盯着它，想起女儿上次回来时拎的也是这样的袋子，里头装着两盒糕点，油渗出来，在袋底积成透明的污渍。

石阶下方有条死鱼，银灰色的鳞片翻起来，露出底下惨白的肉。蚂蚁排着队从鱼眼睛里进出。死的东西总是招虫子，活着的就不会。

他忽然觉得自己的手背痒，低头看，原来是只小飞虫停在上面，翅膀微微颤动。

渡船的马达声从远处传来，闷闷的，像隔了层棉被。老陈站起来，膝盖发出干涩的响声。他掸了掸裤子上的灰，虽然并没有什么灰可掸。塑料袋已经漂远了，死鱼还躺在那里。船靠岸时掀起的水波漫过石阶，槐树叶子晃了晃，终究没被冲走。

乘客陆续下船。老陈伸长脖子看，又慢慢缩回来。他摸出最后一根烟，这次打火机一次就着了。

风停了。

# 祷词

## 序

冰原的夜晚比死亡更安静。他蜷在兽皮堆里，数着肋骨下微弱的心跳。风从岩缝钻进来，舔舐他裸露的脚踝，像某种活物在试探血肉的温度。

梦中，他听见冰层深处传来碎裂声。

人们挤在岩窟最深处，围着那团将熄的火。火光照不亮洞顶垂下的冰棱，只在每张脸上投下颤抖的阴影。有人咳嗽，声音闷在皮袄里，像折断的树枝。没人说话。说话会浪费热气。

他摸到洞口。月光在冰原上铺开，惨白如新剥的骨。远处，那道裂痕正在扩大——冰河在移动，像巨兽翻身时绷裂的皮肤。明天又得往南迁徙。可南边是绝壁，绝壁后面还是冰。

岩缝里的风突然停了。

祂就站在月光里。

祂没有形状。他只记得祂的那双眼睛恒定不变：纯粹的紫，比极光更深邃，像能吸走所有温度的冰窟。

"冷吗？"祂问。声音不是从耳朵进来，是直接在他脑中响起的。

他想张开嘴，但祂已经知道了答案。祂转向岩窟，那里正传出婴儿的啼哭，很快被什么捂住了。

"给我一个名字。"祂说，"我就给你们火焰的形状。"

冰原上没有名字。人们用疤痕、用缺指的手、用冻掉的耳朵互相辨认。但此刻他舌尖突然涌出陌生的音节：“烬......”

紫眼睛弯成新月。冰层深处有什么东西在苏醒。

三天后，他们在冰窟中找到了那块石头。暗紫色，微温，像刚熄灭的炭。当最老的女人颤抖着捧起它时，石头突然迸出光焰。不是橘红色，是接近黑的深紫，却让岩壁上的霜瞬间汽化。人们惊叫着后退，又忍不住凑近伸出发紫的手。

"不够。"他说。祂在梦里警告过：这火种吃念头，吃得越多，烧得越旺。

第一个站出来的是断臂猎人。他把完好的左手按在石头上，闭上眼睛。石头突然明亮起来，紫光里浮出猎人的记忆：雪兔从陷阱挣脱的瞬间，幼狼对着月亮的第一声嚎叫，妻子死在迁徙路上的那个黎明。光焰蹿到洞顶，融化的冰水像眼泪滴在石头上滋滋作响。

人们一个接一个上前。孕妇交出未出世孩子的啼哭，老人献上亡妻头发里的碎雪。轮到那个总在岩壁上刻线的男孩时，他犹豫了。"我只有这个。"男孩摊开掌心，是半块透明的冰，里面冻着一片羽毛。石头吞下冰块的刹那，所有人都闻到了春天沼泽的气味。

最后是他。他捧着石头走进冰窟深处。石头在掌心发烫，催促着。他想起祂说的话："总得有人成为柴薪。"

他带来了石头，他是命运选中的柴薪。

但是祂也说，柴薪不会死去，因为还剩下柴炭。

极光在头顶扭曲成拱形，像未完成的穹顶。他解开皮袄，把石头贴在胸口。剧痛比预想中来得慢——先是温暖，然后是灼烧，最后才是皮肤碳化时的撕裂感。奇怪的是，他闻到了松脂香。

黑暗降临前，他看见自己的记忆正被抽成丝：母亲用狼骨梳头的背影，冰湖里游动的银鱼，还有岩缝中一簇倔强的地衣。这些丝线在空中交织，逐渐编织成某种巨大的、发光的结构。人们从岩窟涌出，仰头望着这片越来越密的网。有人开始哭泣。

当最后一丝记忆被抽尽时，整个冰原突然亮如白昼。光网收拢成半球形，边缘沉入地平线。暴风雪撞在这层透明屏障上，碎成无声的雪沫。

岩壁上，刻线的男孩突然指着天空："看！"人们抬头，发现光幕内壁浮现出模糊的图案：断臂猎人的雪兔，老人的亡妻，男孩羽毛边的冰晶，还有他记忆里的银鱼。这些影像微微搏动着，像另一种形式的心跳。

冰原依然寒冷，但风不再切割皮肤。人们围着新火堆坐下，这次没人阻止婴儿啼哭。火堆旁，半融的雪水里漂浮着灰白色絮状物，偶尔闪过一点紫光，像溺毙的萤火虫。

刻线的男孩蹲在水边，用手指拨弄那些灰絮。它们突然聚拢，凝成一小块透明的冰。冰中心，有针尖大的紫光轻轻闪烁。男孩把冰块藏进贴身的皮囊，抬头望向光幕之外——真正的星空第一次如此清晰，又如此遥远。

## 主教与祭司

冰室里的呼吸声很轻。他低头，掌心的冰球正在发烫——那颗祖传的、永不融化的冰核，此刻紫光微弱得像将死的萤火虫。

脚步声震得冰棱簌簌落下。巨人掀开兽皮帘子，带进一股冻肉的腥气。他腰间别着染血的撬棍，油污板结的头发垂到锁骨，像冻住的瀑布。

"又需要柴薪了？"巨人声音沙哑。他盯着主教指间的金属指套——那东西在冰球微光里泛着青灰色，像某种昆虫的外骨骼。

主教没抬头。冰球映出他眼角的皱纹，比去年更深了。他想起父亲临终时的话："每道皱纹里，都住着一个冻死的魂灵。"指套轻轻刮擦冰球表面，发出细碎的、令人牙酸的声音。

"西侧冰柱里的哑女，撑不过今晚。"主教说。“她的愿望不够用了。”冰球突然闪烁，映出一闪而逝的紫光。

巨人冷笑。他解下腰间皮囊，倒出几块暗紫色碎石。那是上次"天启仪式"后，从祭品心脏位置剥落的烬石残渣。"知道孩子们管这叫什么吗？"他碾碎一块石头，紫色粉末飘落在冰面上，"神的骨灰。"

冰室突然震颤。顶缝落下细雪，在主教肩头积成小小的坟冢。巨人凑近，呼出的白汽扑在冰球上，凝成霜花。"你家族守了三百年的秘密，"他压低声音，"不过是场残忍的屠杀！"

主教闭眼。冰球在掌心发烫，烫得他想起七岁那年——父亲带他走进家族密室，满墙冰匣里封冻着历代主教的右手。每只手掌心都有个圆形灼痕，和他现在握着冰球的位置分毫不差。

"没有天幕，他们活不过三个月。"主教睁开眼。冰球紫光突然闪亮，映出他袖口暗红的污渍——今早有个老妇在祭坛前咬破了嘴唇。

巨人突然暴起。他拳头砸在冰壁上，裂纹蛛网般炸开。"那你告诉他们啊！"吼声震落更多冰棱，"告诉那些母亲，她们的孩子正在冰柱里慢慢变成——"

"——变成光。"主教平静地接话。他举起冰球，紫光里浮现无数细小的影子：佝偻的老人，哺乳的妇女，嬉戏的孩童。"你以为他们不知道？"冰球转动，影子扭曲成祈祷的姿势，"可是总得有人成为柴薪。"

沉默像冰层般厚重。巨人呼吸粗重，喉结滚动着咽下什么。他腰间撬棍上的血迹已经发黑，是上周那个少年祭品的。当时那孩子突然笑了，说冰柱里能看见星空。

"至少..."巨人声音突然疲惫。

主教摇头。指套划过冰球，紫光流转间映出穹顶外真实的夜空——比冰柱里所见黑暗百倍，没有星辰，只有永恒的暴雪漩涡。"你没见过真正的夜。"他说，"那才是吃人的东西。"

冰球光芒渐弱。主教起身时，金属指套在冰面留下五道细痕，像某种兽类的爪印。巨人看着那些痕迹，突然想起小时候听过的传说：最初的主教不是人，是跟着神来的兽，皮毛下藏着永不结冰的血。

通道尽头传来羸弱的哭声。主教停步，没回头。"明天天启，"他说，"我会把老人带来。"

巨人独自站在冰室里。他摸出最后一块烬石残渣，紫色微光里，隐约可见冰球映不出的东西：穹顶内壁上，那些搏动的人形阴影正在缓慢地、不可逆转地褪色。

## 主篇

冰壁在身后合拢时，老人听见自己肋骨的呻吟。通道窄得只容侧身，寒气像细针钻进旧伤疤。主教的金属指套压过肩胛的触感还在——不是重量，是某种冰冷的烙印。前方微光浮动，乳白色，恒定如冻住的奶 -- 冰原上已经看不见牛羊了。

冰窟豁然开阔。中央立着冰柱，光从深处渗出。他走近，看见冰里冻结的东西：蜷曲的指节，半张开的嘴，空洞的眼窝结满霜。不是冰雕，是人。姿态像沉睡的胎儿，又像垂死的蛾子扑向灯火。甜腥气黏在舌根，是陈年冻肉混合铁锈的味道。

脚步声。阴影里走出巨人，兽皮裹着山峦般的躯体，油污板结发亮。

“奉献了半辈子，换来个活祭品的身份？”巨人声音沙哑，像砂纸磨过冰面。

老人没回答。冰柱里一张冻结的脸突然眼睫颤动——是上周被带走的哑女。她嘴唇微张，没有声音，但老人听见了。不是此刻的声响，是三十年前风雪夜，自己蜷在祭坛下第一次祈祷的词句：“……赐我暖……”

所有冰雕的嘴唇都开始翕动。母亲的摇篮曲，少年的誓言，垂死者的呢喃……亿万句祈祷在冰层里共振。原来那光，是煮沸的绝望。

巨人摊开手掌。一块暗紫色石头卧在掌心，微温，像刚熄灭的炭。“烬石，”他说，“吃念头的火种。”石头被塞进老人手里，烫得他指骨发麻。冰柱深处，哑女的眼睛转向他，睫毛挂着细小的冰棱。

风暴的咆哮突然撞进冰窟。冰屑雪沫瀑布般从顶缝泻下。巨人低吼淹没在风里，染血的撬棍指向冰柱核心。

冰柱光滑如镜。老人举起烬石，看见映出的自己：眼窝深陷如废弃的矿洞。他想起第一次“天启”的光落在额头，那种熨帖的暖意。原来暖意是偷来的。

石头贴上冰面。

没有声响。紫色纹路蛛网般炸开，冰层内部传来玻璃碎裂的细响。被紫纹舔舐的地方，冰雕们开始融化。它们变成灰蒙的烟，裹着细微的祈愿声飘散。

哑女的面容在烟雾中淡去。

头顶传来金属撕裂的呻吟。恒定光芒疯狂抽搐，明暗交替如同垂死的呼吸。冰窟剧烈摇晃，巨大的冰棱坠落，砸在老人脚边，碎成齑粉。

混乱的尖叫从主厅方向涌来。老人被气浪掀翻，后脑撞上冰壁。视野模糊前，他看见巨人染血的背影冲向摇晃的通道口。祭坛方向传来主教的尖啸，像被掐住脖子的鸟。

黑暗。

寒冷先于意识醒来。不是冰窟那种浸透骨髓的冷，是粗糙的、带着沙砾感的风割在脸上。老人睁开眼。

头顶没有乳白的光。只有一片巨大的、动荡的灰白。暴风雪灌进主厅那个狰狞的豁口，如同天穹破了洞。祭坛不见了，只剩深坑和扭曲的金属残骸。几缕染血的白色毛皮冻在碎冰里，像主教留下的最后印记。

人群在暴雪中奔突，黑色的剪影撞在一起，跌倒，被后来者踩过。一个老妇跪在豁口下，对着翻涌的灰白哭喊：“回来啊！把光还回来！”风雪瞬间吞没了她的声音。她身后，一个孩子茫然地抓了一把雪塞进嘴里。

老人挣扎着想站起，左腿却像不属于自己。低头看，裤管结满暗红的冰晶。他在碎冰里摸索，触到一块坚硬的东西——烬石。紫色褪尽，只剩灰白，轻得像鸟骨。

铁匠的影子晃过来，脸上血和冰渣冻在一起。他怀里紧抱着什么，焦黑的封面，是半本《天幕建造日志》。铁匠跪在背风的断墙后，哆嗦着翻动书页。纸脆得像枯叶，文字大多焦糊。他撕下几页塞进怀里保温，血迹蹭在边缘，像古怪的批注。

火光突然腾起。铁匠用燧石点燃了纸页，微弱的橘红在灰白风暴里跳动。几个黑影被吸引，踉跄着聚拢过来，伸出紫黑的手掌。

老人拖着伤腿爬近。火堆旁，他看见一块奇特的冰。不是天然形成，是人头大小，棱角分明，像刻意切割过。冰里冻着半张熟悉的脸——他自己的脸。嘴角凝固着一丝奇异的弧度，眼窝深处，两点微弱的紫光静静亮着，像烬石最后的余烬，也像暴风雪中迷途的星辰。

铁匠把那块冰小心地放在火堆旁。冰没有融化。两点紫光映着跳跃的火焰，也映着周围几张冻僵的、渴望热源的脸。铁匠翻动焦黑的日志，手指停在某页。模糊的字迹被他的血润开，显出一行断续的话：

“……真星空……人当……怀念此笼……”

火舌舔舐着这行字，光影在冰中那张凝固的脸上晃动。冰里的眼睛映着火光，也映着铁匠低垂的、沾满冰屑的睫毛。风雪在豁口处尖啸。几点橘红的光，在辽阔的灰白里，微弱地亮着。

# 日出

他坐在窗户边上。

东面的天已经有些泛得惨白，西面还是漆黑一片。这是多么奇异的景象呵，东边就要日出，西边的天还星星点点戳着许多光点。

这是他这一生第一次这么认真地看着天空，清晨的天空好冷。

他总感觉在哪里听说过，月亮出来的晚上，会看不到星星。可是他也分明看到现在的月亮就在那里，和星星一起，挂在漆黑的西边。他想了很久，大概一个晚上吧，想他的愿望，想他爱的人，想爱他的人。

可是他失败了。他的脑子里一片空白，很喧哗，很寂静。

现在他的眼睛里应该布满了红血丝。毕竟这还是他第一次通宵。但是还会有谁去在意呢？反正这么大个房子，也就他一个人坐在窗户上。也许遥远的天空，也有一颗星星坐在月亮的边上，陪他吧。太阳再升起一点，星星们就要走了。

他看着东边的天，企盼着那种从未见过的太阳从天边出现。他第一次感受到了那种期盼是什么意思。但是这个太阳真的好冷。终于有一丝阳光照在他的脸上。呵，久违的暖。但是若有若无，被云遮住了。

他看不到太阳了。他又看向西边。黑暗已经被光明占领了大半。月亮像透明的膜，粘在原先的位置。那颗挂在月亮上的，陪他的星星或许已经不见了。

东边的白色的天上是很大一片云，西边的黑色的天上星星隐去了。

他的星星消失了，和他爸爸妈妈的星星一样。

再也找不到了。
